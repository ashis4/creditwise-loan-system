🏦 About CreditWise

CreditWise is an AI-powered loan approval and advisory system designed to assist financial institutions in making data-driven lending decisions.

🔄 Project Workflow

1️⃣ Data Collection

Structured dataset containing applicant financial details.

2️⃣ Data Preprocessing

  • Handling missing values
  • Encoding categorical variables
  • Scaling numerical features

3️⃣ Feature Engineering

  • DTI Ratio
  • Credit Score²

4️⃣ Model Building

Trained machine learning model and evaluated performance.

5️⃣ Deployment

Streamlit-based web app with pickle model integration.

6️⃣ Prediction System

  • Loan approval prediction
  • Confidence score
  • Suggestions for improvement
